#  Planejador Financeiro de Viagens

Sistema desenvolvido em Python para auxiliar no planejamento financeiro de viagens rodoviárias.

## Funcionalidades

-  Cálculo do consumo médio do veículo;
- Cálculo do custo de combustível;
-  Cálculo da autonomia do veículo;
-  Estimativa da quantidade de paradas para abastecimento;
-  Comparação entre dois veículos;
-  Verificação se o custo da viagem está dentro do orçamento.

## Tecnologias

- Python 3

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/ricardopjunkes/planejador-financeiro-viagem.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd planejador-financeiro-viagem
   ```

3. Execute o arquivo principal:

   ```bash
   python main.py
   ```
